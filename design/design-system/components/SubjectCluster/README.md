# SubjectCluster

Illustration d'accueil : les six pastilles de matières inclinées autour du logo.

## Quand l'utiliser

En haut de l'écran de bienvenue, au-dessus du titre. Décorative (masquée aux lecteurs d'écran).

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `height` | `number` | Hauteur (176 par défaut). |
| `logo` | `boolean` | `false` pour retirer le logo central. |

## Exemple

```js
const { SubjectCluster } = window.TutorIA;
```
