# AdviceCard

Conseil aux parents en violet `accent`, avec une ampoule.

## Quand l'utiliser

Bas du tableau de bord ou de la page Progrès. Un seul conseil à la fois.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `title` | `string` | « Comment l'encourager » par défaut. |
| `children` | `node` | Texte. |

## Exemple

```js
const { AdviceCard } = window.TutorIA;
```
