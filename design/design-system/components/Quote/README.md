# Quote

Citation d'accueil, en italique discret, sous le bonjour de l'élève.

## Quand l'utiliser

Une seule citation, en haut de l'accueil élève, à la place de la date.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `text` | `string` | Citation. |
| `author` | `string` | Auteur, affiché en fin de ligne. |

## Exemple

```js
const { Quote } = window.TutorIA;
```
