# TipCard

Encadré « conseil » en violet `accent`, avec une ampoule.

## Quand l'utiliser

Un conseil ponctuel dans le chat (`inChat`, aligné sur les bulles) ou sous une explication. Rare, pour garder son effet.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `title` | `string` | « Conseil » par défaut. |
| `inChat` | `boolean` | Décalé comme une bulle du tuteur. |
| `children` | `node` | Texte. |

## Exemple

```js
const { TipCard } = window.TutorIA;
```
