# AlertCard

Alerte douce (orange) sur un point à surveiller, avec une action.

## Quand l'utiliser

Tableau de bord Parents : notion à consolider, baisse de régularité.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `title` | `string` | Titre. |
| `children` | `node` | Texte. |
| `actionLabel` | `string` | Action. |
| `onAction` | `function` | Action. |
| `href` | `string` | Lien. |

## Exemple

```js
const { AlertCard } = window.TutorIA;
```
