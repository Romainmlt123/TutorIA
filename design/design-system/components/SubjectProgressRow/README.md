# SubjectProgressRow

Progression d'une matière : picto de la matière en couleur, nom, barre et pourcentage.

## Quand l'utiliser

Section « Progression par matière » des statistiques élève (le picto coloré remplace l'ancienne pastille).

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `subject` | `string` | Matière. |
| `value` | `number` | Progression en %. |

## Exemple

```js
const { SubjectProgressRow } = window.TutorIA;
```
