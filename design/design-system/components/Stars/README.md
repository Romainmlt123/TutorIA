# Stars

Trois étoiles de réussite (0 à 3), pleines en orange, vides en gris.

## Quand l'utiliser

Sous un niveau terminé de la carte, dans la fiche d'un niveau et dans le bilan. `onColor` sur un fond coloré.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `value` | `0 \| 1 \| 2 \| 3` | Étoiles obtenues. |
| `size` | `number` | Taille en px (16 par défaut). |
| `onColor` | `boolean` | Version blanche pour fond coloré. |
| `outline` | `boolean` | Contour blanc (sur la carte). |
| `gap` | `number` | Écart entre étoiles. |

## Exemple

```js
const { Stars } = window.TutorIA;
```
