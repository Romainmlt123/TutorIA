# TallyChips

Compteurs de session : cartes sues (vert) et à revoir (orange).

## Quand l'utiliser

Sous la carte de session.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `known` | `number` | Cartes sues. |
| `review` | `number` | Cartes à revoir. |

## Exemple

```js
const { TallyChips } = window.TutorIA;
```
