# ChildSwitcher

Sélecteur de l'enfant suivi, en haut de l'espace Parents.

## Quand l'utiliser

Quand une famille suit plusieurs enfants ; ouvre la liste au clic.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `name` | `string` | Prénom de l'enfant. |
| `grade` | `string` | Classe (4e…). |
| `onClick` | `function` | Ouvre le choix. |

## Exemple

```js
const { ChildSwitcher } = window.TutorIA;
```
