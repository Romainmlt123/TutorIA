# LevelTypePill

Étiquette du type de niveau : pastille dégradée avec l'icône et libellé sur fond doux de la même couleur.

## Quand l'utiliser

Dans la fiche d'un niveau, l'en-tête de discussion et partout où il faut rappeler le type.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `type` | `'lecon' \| 'exercices' \| 'evaluation'` | Type de niveau. |

## Exemple

```js
const { LevelTypePill } = window.TutorIA;
```
