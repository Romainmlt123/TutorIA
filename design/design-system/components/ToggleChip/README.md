# ToggleChip

Puce à cocher avec icône, bordée de bleu une fois choisie.

## Quand l'utiliser

Moments de révision (le matin, après l'école, le soir, le week-end), filtres simples.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `icon` | `string` | Icône. |
| `label` | `string` | Libellé. |
| `selected` | `boolean` | Choisie. |
| `onClick` | `function` | Basculer. |

## Exemple

```js
const { ToggleChip } = window.TutorIA;
```
