# Heatmap

Calendrier d'activité : une case par jour, 5 niveaux d'intensité en bleu.

## Quand l'utiliser

Régularité sur les dernières semaines (stats élève).

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `weeks` | `number[][]` | Semaines × 7 jours, niveaux 0 à 4. |

## Exemple

```js
const { Heatmap } = window.TutorIA;
```
