# RegionSign

Panonceau de région (thème de la matière) : surtitre « Région N » et nom.

## Quand l'utiliser

Sur la carte, en début de chaque région.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `index` | `number` | Numéro de région. |
| `name` | `string` | Nom de la région. |
| `color` | `string` | Couleur du surtitre. |

## Exemple

```js
const { RegionSign } = window.TutorIA;
```
