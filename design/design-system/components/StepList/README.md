# StepList

Liste d'étapes numérotées dans une carte blanche.

## Quand l'utiliser

Instructions courtes : « Sur le téléphone de Léa », premiers pas.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `title` | `string` | Titre. |
| `icon` | `string` | Icône du titre. |
| `tone` | `'eleve' \| 'parents'` | Couleur des numéros. |
| `steps` | `string[]` | Étapes. |

## Exemple

```js
const { StepList } = window.TutorIA;
```
