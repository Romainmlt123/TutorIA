# Checkbox

Case à cocher 24px avec son texte, bleue côté élève, violette côté parent.

## Quand l'utiliser

Conditions d'utilisation, abonnement au bilan de la semaine.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `checked` | `boolean` | État. |
| `onChange` | `(checked) => void` | Changement. |
| `tone` | `'eleve' \| 'parents'` | Couleur. |
| `children` | `node` | Texte. |

## Exemple

```js
const { Checkbox } = window.TutorIA;
```
