# MapAvatar

Avatar de l'élève qui flotte au-dessus du niveau en cours (initiale dans une pastille bleue).

## Quand l'utiliser

Sur la carte, au-dessus du point actif (placé par `WorldMap`).

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `initial` | `string` | Initiale de l'élève. |

## Exemple

```js
const { MapAvatar } = window.TutorIA;
```
