# OrDivider

Séparateur « ou » entre le formulaire et les connexions Apple / Google.

## Quand l'utiliser

Écrans de connexion et d'inscription, toujours sous le bouton principal.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `label` | `string` | « ou » par défaut. |

## Exemple

```js
const { OrDivider } = window.TutorIA;
```
