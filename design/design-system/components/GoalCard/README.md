# GoalCard

Objectif du jour : anneau de progression, titre et détail.

## Quand l'utiliser

Accueil élève, sous les cartes de jeu.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `done` | `number` | Réalisé. |
| `total` | `number` | Objectif. |
| `title` | `string` | « Objectif du jour » par défaut. |
| `detail` | `string` | Détail. |
| `badge` | `string` | Pastille à droite (ex. « +20 XP »). |

## Exemple

```js
const { GoalCard } = window.TutorIA;
```
