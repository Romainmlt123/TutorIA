# SessionProgress

Barre d'avancement d'une session de flashcards avec le compteur « 4 / 12 ».

## Quand l'utiliser

En haut de l'écran de session.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `value` | `number` | Carte en cours. |
| `total` | `number` | Total. |
| `subject` | `string` | Matière (couleur de la barre). |

## Exemple

```js
const { SessionProgress } = window.TutorIA;
```
