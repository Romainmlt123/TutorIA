# ChapterRow

Ligne de chapitre à réviser : numéro dans la couleur de la matière, titre, cartes et durée.

## Quand l'utiliser

Liste des chapitres après le choix d'une matière en flashcards.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `index` | `number` | Numéro. |
| `title` | `string` | Chapitre. |
| `cards` | `number` | Nombre de cartes. |
| `minutes` | `number` | Durée. |
| `subject` | `string` | Matière. |
| `selected` | `boolean` | Sélectionné. |
| `onClick` | `function` | Action. |

## Exemple

```js
const { ChapterRow } = window.TutorIA;
```
