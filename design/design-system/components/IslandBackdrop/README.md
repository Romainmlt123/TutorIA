# IslandBackdrop

Fond d'écran du chat d'un niveau aux couleurs de l'île : dégradé doux de la matière, motifs et île miniature en haut à droite.

## Quand l'utiliser

Derrière la discussion écrite ou vocale d'un niveau (X4). Le contenu passe en `children`.

## Props

| Prop | Type | Rôle |
| --- | --- | --- |
| `subject` | `SubjectId` | Matière de l'île. |
| `height` | `number \| string` | Hauteur (100 % par défaut). |
| `children` | `ReactNode` | Contenu posé sur le fond. |

## Exemple

```js
const { IslandBackdrop } = window.TutorIA;
```
